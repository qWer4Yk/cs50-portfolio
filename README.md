## 📚 Алгоритмы и Coursework (Problem Sets)

### 🧱 CS50x: Week 1 — Язык C

Переход к низкоуровневому программированию, ручному управлению памятью и строгой типизации.

- **Mario (Less & More):** Работа с вложенными циклами и форматированием вывода.
- **Cash:** Реализация жадного алгоритма (Greedy Algorithm) и решение проблемы точности чисел с плавающей точкой (Floating Point).
- **Credit:** Валидация кредитных карт с помощью алгоритма Луна (Luhn's Algorithm) и целочисленной арифметики.
