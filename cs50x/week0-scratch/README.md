# 🐱 Week 0: Scratch Project

## Описание
Это мой первый проект в рамках курса CS50x. Я создал интерактивную игру/историю [Hungry monkey], чтобы продемонстрировать базовые концепции программирования: циклы, условия и обработку событий.

## Как запустить
1. Скачайте файл `project.sb3` из этой папки.
2. Зайдите на [scratch.mit.edu](https://scratch.mit.edu/).
3. В редакторе нажмите **File -> Load from your computer** и выберите скачанный файл.
4. Нажмите зеленый флаг, чтобы начать!
